# YOLO 环境离线安装指南

## 🚨 当前状态

由于网络连接问题，自动安装遇到困难。以下是几种解决方案：

## 📦 方案 1：手动下载安装包（推荐）

### 1. 下载必要的 wheel 文件

访问以下链接下载对应的.whl 文件：

**PyTorch CPU 版本:**

- https://download.pytorch.org/whl/torch_stable.html
- 选择: `torch-2.0.1+cpu-cp39-cp39-win_amd64.whl`
- 选择: `torchvision-0.15.2+cpu-cp39-cp39-win_amd64.whl`

**ultralytics:**

- https://pypi.org/project/ultralytics/#files
- 下载最新版本的.whl 文件

**其他依赖:**

- opencv-python: https://pypi.org/project/opencv-python/#files
- numpy: https://pypi.org/project/numpy/#files
- pillow: https://pypi.org/project/Pillow/#files
- matplotlib: https://pypi.org/project/matplotlib/#files

### 2. 安装命令

```bash
# 激活环境
conda activate yolo-env

# 安装下载的wheel文件
pip install torch-2.0.1+cpu-cp39-cp39-win_amd64.whl
pip install torchvision-0.15.2+cpu-cp39-cp39-win_amd64.whl
pip install ultralytics-8.0.0-py3-none-any.whl
pip install opencv_python-4.8.0.74-cp39-cp39-win_amd64.whl
pip install numpy-1.24.3-cp39-cp39-win_amd64.whl
pip install Pillow-10.0.0-cp39-cp39-win_amd64.whl
pip install matplotlib-3.7.2-cp39-cp39-win_amd64.whl
```

## 📦 方案 2：使用 conda-forge（如果网络允许）

```bash
conda activate yolo-env
conda install -c conda-forge pytorch torchvision ultralytics opencv -y
```

## 📦 方案 3：配置代理或镜像源

### 配置 pip 镜像源

```bash
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
pip config set global.trusted-host pypi.tuna.tsinghua.edu.cn
```

### 配置 conda 镜像源

```bash
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/main/
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/free/
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/cloud/conda-forge/
conda config --set show_channel_urls yes
```

## 🧪 测试安装

安装完成后，运行测试脚本：

```bash
python test_environment.py
```

## 🎯 最小化安装（仅推理）

如果您只需要进行推理而不需要训练，可以尝试最小化安装：

```bash
conda activate yolo-env
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
pip install ultralytics
```
