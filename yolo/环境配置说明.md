# YOLO 环境配置说明

## 🎯 环境概述

- **环境名称**: yolo-env
- **Python 版本**: 3.9
- **包管理**: Conda 虚拟环境（完全隔离）
- **位置**: `C:\Users\taogu\.conda\envs\yolo-env`

## 🚀 快速开始

### 1. 激活环境

```bash
conda activate yolo-env
```

### 2. 安装依赖包

```bash
# 方案1：使用requirements.txt（推荐）
pip install -r requirements.txt

# 方案2：使用国内镜像源（如果网络有问题）
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
pip install -r requirements.txt

# 方案3：使用conda（如果pip有问题）
conda install -c conda-forge pytorch torchvision ultralytics opencv -y
```

### 3. 验证安装

```bash
python -c "import ultralytics; print('YOLO安装成功!')"
```

## 🔧 网络问题解决

如果遇到网络连接问题，请尝试：

1. **使用国内镜像源**:

```bash
pip config set global.index-url https://pypi.tuna.tsinghua.edu.cn/simple
pip config set global.trusted-host pypi.tuna.tsinghua.edu.cn
```

2. **使用 conda-forge**:

```bash
conda install -c conda-forge ultralytics pytorch torchvision -y
```

3. **离线安装**:
   - 下载 wheel 文件到本地
   - 使用 `pip install 本地文件路径`

## 📝 代码修复说明

您的 `main.py` 文件中的路径需要修复：

**修复前**:

```python
results=model("D://AIGC/yolo/img/12.jpg")
```

**修复后**:

```python
import os
# 使用相对路径，更便携
img_path = os.path.join("img", "12.jpg")
results = model(img_path)
```

## 🎮 使用方法

1. 激活环境: `conda activate yolo-env`
2. 运行代码: `python main.py`
3. 退出环境: `conda deactivate`

## 🔍 故障排除

- **ImportError**: 确保已激活 yolo-env 环境
- **CUDA 错误**: 当前安装的是 CPU 版本，如需 GPU 支持请安装 CUDA 版本
- **路径错误**: 检查图片路径是否正确
