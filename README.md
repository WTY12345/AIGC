# AIGC
## Project objective

This team project is from NJUPT. The main members are Wu Tianyu, Hu Lean, Wang Puli, Jin Yuxuan and Tao Gutao. The main task is to quantitatively assess the aesthetic quality of a lock screen or a person's image.





First of all, our primary task is to determine how to quantify the aesthetic quality of an image. We divide it into the following aspects (being updated continuously):

The resolution of the image.

The balance of the main body of the picture.

The color of the picture.

......



Although we have identified these factors. However, the specific handling of each item remains an important issue. We hope that someone can offer help.





Our other task is to create a graphical interface for selecting input images and presenting our calculation results. We plan to solve it using QT.
